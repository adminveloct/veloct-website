# Website VeloCT

Website company profile VeloCT dua bahasa (Indonesia/Inggris). Bagian dari Internal Platform Project.

> **Status:** persiapan. Kerangka aplikasi akan ditambahkan setelah teknologi disetujui.

## Ruang lingkup MVP

- Halaman: Beranda, Tentang Kami, Layanan/Produk, Kontak, dan Kebijakan Privasi
- Dua bahasa: Indonesia (`/id`) dan Inggris (`/en`)
- Formulir Kontak dengan pengiriman lewat Gmail

## Teknologi (usulan)

Next.js (App Router) + TypeScript, Tailwind CSS + shadcn/ui, GitHub Actions, dan Vercel. Ditambah next-intl untuk dua bahasa.
